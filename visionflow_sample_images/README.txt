VisionFlow sample images
========================
good/    - normal parts (the AI should say "Looks fine")
defect/  - parts with a visible defect: scratch / stain / hole / dent
           (the AI should say "Defect found", or "Needs a person" if borderline)

Drag any of these onto the "Check Image" page in the VisionFlow app.
These are synthetic but real PNGs. For real industrial photos, see the
README section "Using the real MVTec dataset".
